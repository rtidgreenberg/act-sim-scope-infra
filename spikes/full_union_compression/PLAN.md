# Full union compression qualification

Compare none, LZ4 and zlib on a fresh current processor build, without deployment.
Use three gateways with complete ACT monitoring, mission receive policy, the
six-topic IPv6 WAN contract, asynchronous publishing and the shared 4 Mbps
controller. Preserve the two priority bands and native delivery policies.

1. Reproduce any baseline failure before adding compression.
2. After authorized baseline repairs, rebuild privately and validate type round
   trips. Never overwrite the persistent router build.
3. Run none/LZ4/zlib, then reverse the order, on isolated loopback domains.
4. Require exact commands/ACKs, distinct contacts, paced final periodic markers,
   intended mission-policy exclusions and contact dispose/revival.
5. Read effective QoS and compare normalized generated XML. Attribute actual
   packet bytes to native writers and both priority channels, including native
   DATA_FRAG_SESSION. Check capture drops and native errors explicitly.
6. Retain configuration, hashes, logs, captures and before/after summaries.

This does not qualify EMANE/radio behavior, a binary codec, arbitrary filtering
transitions, unregister, prolonged loss/recovery or fleet-scale capacity.
